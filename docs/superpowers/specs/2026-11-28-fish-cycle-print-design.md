# Print one fish production cycle from a computer

Approved by the user on 2026-11-28 ("proceed").

## Why

An office account on a computer cannot print one production cycle. The phone card in Aquaculture Monitoring can. The row menu had **Print Report**
until PR #178 (2026-11-04) took it off, when a Print Report button above the table remained. PR #184 (2026-11-05) removed that button.

## What

- **Print Report** is back in the ⋮ menu of every row of Aquaculture Monitoring, after Activity Logs. Every account that sees the menu gets it,
  on harvested cycles too.
- It prints the same report as the phone's Print button: the cycle's details, its ponds or cages, and the Prepared by and Noted by lines.
  Feeding and health logs are not in it.
- Help says so, and the menu's Help picture is retaken.

## Approaches

1. **Row ⋮ menu** (chosen): one more line in a list people already use, like Print report on a farm parcel.
2. A printer icon beside the fishing net: one click, but a more crowded Actions column.
3. A button inside View Details: more clicks, and the fisherfolk screens use that window too.

## Not in this change

Phone and fisherfolk screens, the report's contents, the server and the database. No button above the table.
